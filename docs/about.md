## Projects

- [`filtersql`](https://filtersql.org) — a SQL query compiler with
  multi-tenant scope and column whitelisting. It started as a tiny bug
  that turned out to be an architectural problem:
  [I wrote about it here](blog/posts/2026-10-02-analisi-di-un-bug-filtersql.md).
- [`adminer-plugin-dump-markdown`](https://github.com/fthiella/adminer-plugin-dump-markdown)
  — an [Adminer](https://www.adminer.org/) plugin that exports tables
  and queries to Markdown, ready to paste into an email, a blog post,
  or a document.
- **Document RAG** *(internal project)* — a retrieval-augmented
  generation system over roughly 30,000 public sector documents.
  They weren't freely available, so I collected, cleaned and cataloged
  them with my own scripts, OCR'd them with a custom pipeline, tagged
  them via AI APIs, and finally made them searchable both with classic
  search and with an LLM. Stack: Python, PostgreSQL with `pgvector`.
  No link: the documents and the infrastructure aren't mine.
- [`SQL::Textify`](https://metacpan.org/pod/Sql::Textify) — a Perl
  module to run SQL queries from the command line and get results in
  Markdown, HTML or JSON.
- [`Sql-mk-builder`](https://github.com/fthiella/Sql-mk-builder) — the
  older version of `SQL::Textify`, integrable with Sublime Text.
- A few more on [GitHub](https://github.com/fthiella).
